# かんたんAI親方 ロープワーク（試作）

**スマホを立てて、画面の中に手を入れて結ぶ。AIが見て、声と重ね表示で教える。**

「かんたんAI親方」（手元の作業をカメラで写し、AIが分析して、声と重ね映像でアドバイスする）の考え方を、
ARグラスの前に **スマホ1台** で試すための、ロープワーク版です。

## しくみ

| 部分 | どこで動くか | 速さ | やること |
|---|---|---|---|
| 手の追跡 | スマホの中（MediaPipe Hand Landmarker） | リアルタイム | 両手の位置を見つけ、**見本の図を両手の間に重ねる**。手が止まったことを見つける |
| 見本の図 | スマホの中（手描きのSVG） | すぐ | ステップごとのロープの形。動かす端を黄色の点線、動かす向きをオレンジの矢印で表示 |
| 結び目の確認 | Claude（クラウド） | 数秒 | 「これで良い？」と聞くか、**手を3秒止める**と、今の結び目がステップどおりかを判定 |
| 声 | スマホの中 | すぐ | 手順の読み上げ。「次」「戻る」「もう一回」「これで良い？」を聞き取る |

## 結び方（最初の2つ）

- **8の字結び**（やさしい）：ロープの端が抜けないようにする止め結び
- **本結び**（ふつう）：2本の端をつなぐ・荷物をしばる。最後に「縦結び」になっていないかをAIが確認

## 使い方

1. スマホをスタンドに立て、画面を自分に向けて、50cmくらい離して置く
2. 結び方をえらんで「はじめる」
3. ロープを両手で持って、画面の中に手を入れる（鏡のように映る）
4. 手の間に重なる見本と声の案内どおりに結ぶ
5. 「これで良い？」と聞くか、手を3秒止めると、AIが ⭕ できている／🔧 直すところ／👀 見えない を答える。⭕ なら次のステップへ進む

## 動かし方

```bash
cd github/kantan-ai-oyakata-rope
npx serve .
```

- PC：`http://localhost:3000` を開く（Webカメラで試せます）
- スマホ：カメラは **https** でしか使えないため、GitHub Pages などで公開して開きます
- ⚙ 設定で Claude APIキーを保存します（手の追跡と見本はキーなしでも動きます）

## プライバシー

- 手の追跡はスマホの中だけで行います
- AIに送るのは、確認のときの1コマだけです。映像は保存しません

## 注意

- **練習用です。** 人の体重を支える、高い所、登山、救助、荷物を吊り上げる用途には使わないでください（専門の講習を受けてください）
- ロープを首に巻かないでください。小さな子どもが使うときは大人がそばにいてください
- AIはロープの上下の重なりを見間違えることがあります

## これから

- もやい結び、巻き結び（クローブヒッチ）、ねじ結び など結び方を増やす
- ロープそのものを追跡して、見本の線を実物のロープに沿わせる
- ARグラス版：手元を見たまま、目の前に見本と矢印を重ねる
- 同じしくみで、ほかの「手元の作業」（裁縫、配線の結束、包装、手術の糸結びの練習など）へ広げる
